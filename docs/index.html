01 / Первые 15 минут

Сначала база, потом магия

Не спеши превращать свежую систему в археологический слой из случайных репозиториев. В Nobara уже есть нормальный маршрут.

  1. 1

    0-3 минуты: Nobara Welcome

    Открой приветственное приложение и пройди начальные пункты. Если система предлагает обновление, соглашайся через штатный интерфейс.
  2. 2

    3-10 минут: обновление

    Используй Nobara System Updater в GUI или nobara-sync. Без sudo и без sudo dnf upgrade.
  3. 3

    10-12 минут: Media Codecs

    На вопрос об установке медиакодеков отвечай YES. Иначе H.264, H.265 и FFmpeg устроят тебе квест прямо перед эфиром.
  4. 4

    12-15 минут: приложения

    qBittorrent, Vesktop и Chrome ставь через DNF App Center, Nobara Welcome или Flathub строго в режиме User. Discover в этом гайде не участвует.
Священное правило Nobara
Для обновления всей системы запускай nobara-sync. Он выполняет Nobara-специфичные миграции и исправления, которые обычный DNF не знает. Команда nobara-sync --all дополнительно обновит Flatpak.
Обычное обновление системы
nobara-sync
RPM + Flatpak одним заходом
nobara-sync --all
Обязательно

Media Codecs

H.264/H.265, x264/x265 и FFmpeg нужны браузеру, играм, OBS и почти всему, что не выводит звук азбукой Морзе.
Без дублей

Flatpak только User

Не смешивай User и System установки. Иначе получишь два приложения, три runtime и четыре причины спросить: кто это сделал?
Стабильный путь

Дополнительные диски

Подключай через Nobara Drive Mount Manager. Игровой путь будет жить в /run/media/ты/uuid и не испарится после ребута.
qBittorrent + Vesktop + Chrome как Flatpak User
flatpak install --user flathub org.qbittorrent.qBittorrent dev.vencord.Vesktop com.google.Chrome
Не трогай кнопку хаоса
sudo dnf upgrade здесь не герой, а мужик с ломом возле электрощита. DNF можно использовать для установки конкретных пакетов, но обновляй Nobara только штатно.
02 / Экран и ввод

165 Гц для игры, 60 Гц для чата, ноль киселя

Plasma 6 на Wayland умеет разную герцовку для каждого экрана. Но VRR и старый Polaris иногда собирают микростаттер-пати без твоего приглашения.

Проверь кабель
Для высокой герцовки и Adaptive Sync предпочти DisplayPort. В списке режимов выбери максимальную стабильную частоту, а не ту, которую HDMI вспомнил из прошлой жизни.

Начни отсюда

VRR включается для полноэкранной игры, когда приложение и монитор это поддерживают.

  • На Acer выставь 144 или 165 Гц.
  • Adaptive Sync оставь Automatic.
  • ViewSonic держи на честных 60 Гц.
  • Проверь игру с открытым видео или чатом на втором экране.
Почему это работает
Mixed-refresh сам по себе поддерживается KWin, но VRR, второй 60-Гц экран и разные сценарии композитинга могут давать неровный frametime. Переключение Automatic/Never - нормальный диагностический тест, а не религия.
Без ускорения

Мышь Flat 1:1

Параметры системы - Мышь - Профиль ускорения - Flat. Это убирает зависимость ускорения от скорости руки. Ползунок скорости остается обычным множителем.
Есть цена

KWallet без попапа

Либо создай кошелек с пустым паролем, либо отключи подсистему KDE Wallet в настройках. Оба варианта снижают защиту токенов и паролей. Безопаснее пароль входа + автоматическая разблокировка.
Минус индексация

Baloo на диете

Если поиск по содержимому файлов не нужен, отключи индексатор. На 16 ГБ это убирает лишнюю фоновую возню, но поиск станет проще и глупее.
Отключить Baloo в Plasma 6
balooctl6 disable
Проверить статус индексатора
balooctl6 status
03 / RX 580 и LACT

Дадим Polaris прохладу, а не похоронный марш вентиляторов

RX 580 отлично дружит с Mesa и amdgpu. LACT дает удобный контроль напряжения, лимита мощности и вентилятора, но каждое изменение проверяем нагрузкой.

Linux

Mesa + amdgpu

  • Драйвер уже в ядре и Mesa, отдельный Adrenalin не нужен
  • Wayland, Vulkan и VAAPI работают одним открытым стеком
  • После сбоя GPU ядро может восстановить драйвер без полного ребута
Windows

Adrenalin + TDR

  • Windows следит за зависанием GPU через Timeout Detection and Recovery
  • Черный экран может завершиться перезапуском драйвера или приложения
  • Это не делает Linux бессмертным: плохой андервольт валит оба лагеря

Установка LACT

Fedora 43 / Nobara 43

Старый идентификатор ilya-zlobintsev/LACT из древних видосов не используй. Актуальный COPR проекта - ilyaz/LACT.

1. Подключить актуальный COPR
sudo dnf copr enable ilyaz/LACT -y
2. Установить LACT
sudo dnf install lact -y
3. Запустить демон
sudo systemctl enable --now lactd
Здесь DNF можно
Ты ставишь конкретный пакет, а не обновляешь Nobara в обход ее синхронизатора. Это нормальный сценарий.

Открываем OverDrive для Polaris

Маска ниже специфична для RX 470/480/570/580. Она включает нужные PP-функции и отключает биты GFXOFF/STUTTER.

Добавить параметр ядра
sudo grubby --update-kernel=ALL --args='amdgpu.ppfeaturemask=0xfffd7fff'
Перезагрузиться
systemctl reboot
Проверить параметр после загрузки
cat /proc/cmdline
Не универсальная таблетка
0xfffd7fff может повысить потребление в простое или конфликтовать с отдельными multi-monitor конфигурациями. Если после нее ловишь черный экран или странный idle, откатывай.
Откат параметра
sudo grubby --update-kernel=ALL --remove-args='amdgpu.ppfeaturemask=0xfffd7fff'
Калькулятор андервольта

Сдвинь напряжение, но не здравый смысл

Модель показывает возможный эффект для RX 580. Это ориентир, а не договор с физикой и твоим конкретным кристаллом.

04 / Игры

PortProton: запускаем, изолируем, не варим префикс-солянку

PortProton собирает Wine/Proton, DXVK, VKD3D и настройки в один внятный запускатор. Qt - это интерфейс, а не магически другой движок.

Среда запуска

PortProton

  • Скрипты и окружение для запуска Windows-игр
  • Управляет Wine/Proton, DXVK, VKD3D и переменными
  • Создает и обслуживает отдельные игровые префиксы
Графический слой

PortProtonQt

  • Qt-интерфейс поверх возможностей PortProton
  • Удобные карточки, настройки и список приложений
  • Не отдельная совместимость и не другой Proton
Автоустановка

Lesta Game Center

В PortProton открой раздел автоустановки, выбери Lesta Game Center, дождись готового префикса и уже внутри поставь нужную игру. Не запускай клиент из случайного общего Wine-префикса.
Отдельный префикс

setup.exe локальной копии

Для законно полученного установщика нажми правой кнопкой по setup.exe и открой через PortProton. Ссылок на пиратские раздачи тут нет, кент не подставляет кента.
Drive Mount Manager

Путь к библиотеке

Дополнительный SSD или HDD сначала добавь в Nobara Drive Mount Manager. Иначе сегодня библиотека есть, завтра Wine смотрит в пустоту как бывшая в переписку.

FitGirl / DODI setup.exe: безопасный маршрут

Технически это обычный Windows-инсталлятор, но происхождение файла и лицензия остаются твоей ответственностью.

Риск
  1. 1

    Создай новый префикс

    Одна игра - один префикс. Так поломанный DLL override не утянет соседей на дно.
  2. 2

    Запусти setup.exe через PortProton

    Не через системный Wine и не двойным кликом в неизвестность.
  3. 3

    Сними DirectX и Visual C++

    Убери галочки с bundled DirectX и Visual C++ runtimes. PortProton поставит совместимые компоненты сам.
  4. 4

    Выбери стабильный путь

    Ставь в каталог на диске, подключенном через Drive Mount Manager.
  5. 5

    После установки создай ярлык

    Укажи основной exe игры, проверь DXVK и только потом добавляй MangoHud или Gamescope.

06 / Dual-boot и команды

Windows и Nobara на одном NVMe без битвы за часы

Один диск на 512 ГБ требует аккуратности: отдельные разделы, запас места в EFI, отключенный Fast Startup и часы Windows в UTC.

Один NVMe - не лучший, но рабочий вариант
Nobara Wiki предупреждает, что dual-boot на одном диске повышает риск проблем с EFI и загрузчиком после крупных обновлений Windows. Перед разметкой сделай резервную копию, не форматируй существующий EFI-раздел и оставь ему достаточно свободного места. Если можешь выделить второй диск - будет спокойнее.

Windows 11: часы в UTC

Открой Терминал или CMD от имени администратора. После команды полностью перезагрузи обе системы.

Windows Terminal от администратора
reg add "HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /d 1 /t REG_DWORD /f
Nobara должна хранить RTC в UTC
timedatectl set-local-rtc 0
Еще один саботажник
Отключи Fast Startup в Windows. Иначе она оставляет разделы и железо в полууснувшем состоянии, а Linux потом получает квест без подсказок.

GRUB: меню на 10 секунд

Показываем меню, выставляем таймаут и перестраиваем конфигурацию.

Всегда показывать меню
sudo grub2-editenv - unset menu_auto_hide
Выставить таймаут 10 секунд
sudo sed -i 's/^GRUB_TIMEOUT=.*/GRUB_TIMEOUT=10/' /etc/default/grub
Перестроить конфигурацию GRUB
sudo grub2-mkconfig -o /boot/grub2/grub.cfg
