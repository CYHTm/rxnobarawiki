01

После установки

Сначала обновление и кодеки. Остальное потом.

Открой Nobara Welcome

Пройди начальные пункты и запусти штатное обновление, если оно появилось. Никаких левых репозиториев пока не добавляй.

Обнови систему

важно
Через GUI используй Nobara System Updater. Через терминал используй только nobara-sync. sudo dnf upgrade не тыкай, долбоеб. Это Nobara, не чистая Fedora.
Нужно обновить еще и Flatpak?
RPM + Flatpak
nobara-sync --all
Запускать без sudo
nobara-sync

На Media Codecs нажми YES

не пропускай
Просто жми YES. Без кодеков потом отвалятся видео, запись или браузер, а вспоминать эту галочку будешь уже перед стримом.

Поставь qBittorrent, Vesktop и Chrome

Вставь команду ниже. Она поставит все три приложения в твой пользовательский Flatpak. Режим System не выбирай. Discover здесь не нужен.
Flatpak User
flatpak install --user flathub org.qbittorrent.qBittorrent dev.vencord.Vesktop com.google.Chrome

Подключи дополнительные диски через Drive Mount Manager

Открой Nobara Drive Mount Manager и включи автомонтирование. Иначе после перезагрузки путь к играм может поменяться, и PortProton охуеет вместе с тобой.
Где потом искать диск?
Обычно он будет доступен по пути /run/media/твой_пользователь/uuid. Этот путь и указывай для игровых библиотек.
02

Мониторы и мышь

Acer работает на 75 Гц, ViewSonic на 60 Гц. Настраиваем каждый отдельно.

Выставь правильную частоту

Acer75 Гц / основной
ViewSonic60 Гц / второй
СеансWayland

Путь: Параметры системы - Экран и монитор - Конфигурация экрана.

Проверь Adaptive Sync

Если пункт доступен, сначала поставь Automatic. Если курсор, видео на втором экране или игра начинают дергаться, ставь Never на обоих экранах и проверяй снова. Не дергается - не крути настройку ради науки.
Почему два монитора иногда дергаются?
У экранов разная частота, а RX 580 старая. Иногда VRR и два разных режима дают неровный frametime. Тебе не надо знать внутренности KWin, просто сравни Automatic и Never.

Поставь мышь в режим Flat

Параметры системы - Мышь - Профиль ускорения - Flat. Получишь прямое движение без ускорения от скорости руки. Ползунок скорости выставь как удобно.

Убери KWallet и Baloo, если они бесят

Когда KWallet попросит создать кошелек, оставь оба поля пароля пустыми. Или открой Параметры системы - Безопасность и конфиденциальность - Бумажник KDE и отключи подсистему. Пустой пароль удобнее, но сохраненные токены защищены хуже. Тут без приколов, это реальный минус.
Отключить индексацию файлов
balooctl6 disable
Как вернуть Baloo
Включить индексацию обратно
balooctl6 enable
03

RX 580 и LACT

Ставим управление видеокартой, снижаем напряжение и не пытаемся сразу поставить рекорд мира.

Установи LACT

После выполнения открой LACT из меню приложений. Старый адрес ilya-zlobintsev/LACT из старых гайдов не используй, актуальный называется ilyaz/LACT.
Установка и запуск
sudo dnf copr enable ilyaz/LACT -y
sudo dnf install lact -y
sudo systemctl enable --now lactd

Разреши LACT менять напряжение

только RX 580
Вставь команду, перезагрузи ПК и снова открой LACT. Все. Запоминать эту кашу из цифр нахер не нужно.
Что эта команда вообще делает?
По умолчанию драйвер прячет часть управления RX 580. Параметр открывает напряжение и лимит мощности для LACT. Маска рассчитана на Polaris, то есть RX 470/480/570/580. Она также отключает GFXOFF/STUTTER, поэтому на отдельных системах может вырасти расход в простое.
После команды началась херня? Откатить
Убрать параметр
sudo grubby --update-kernel=ALL --remove-args='amdgpu.ppfeaturemask=0xfffd7fff'

После отката перезагрузи ПК.

Добавить параметр и потом перезагрузиться
sudo grubby --update-kernel=ALL --args='amdgpu.ppfeaturemask=0xfffd7fff'

Начни с 1125 мВ и тестируй

Поставь 1125 мВ, сохрани профиль и погоняй реальную игру 15-30 минут. Потом снижай по 10-15 мВ. Артефакты, вылет или черный экран - верни предыдущий шаг. Не ебашь сразу 1065 мВ, карта тебе ничего не должна.

04

Игры

PortProton, отдельные префиксы и нормальные пути к дискам.

Поставь PortProton

Сначала поищи PortProton в Nobara Welcome или DNF App Center. Если там нет, используй команду. Lesta Game Center ставится из раздела автоустановки внутри PortProton.
PortProton и PortProtonQt - в чем разница?
PortProton запускает Windows-игры через Wine/Proton. PortProtonQt - его графический интерфейс. Это не два разных движка, выбирать между ними как между Wine и Proton не надо.
Если пакета нет в Nobara Welcome
sudo dnf copr enable boria138/portproton -y
sudo dnf install portproton -y

Одна игра - один префикс

Для локального setup.exe выбери запуск через PortProton и создай новый префикс. В установщике сними галочки DirectX и Visual C++, PortProton поставит нужное сам. Не пихай все игры в один префикс, потом сам хер найдешь, какая из них все сломала.
Коротко про FitGirl и DODI
Технически их setup.exe запускается так же. Используй только законно полученные файлы и проверяй их источник. Сайт не раздает репаки и не ведет на пиратские ссылки.
Захват OpenGL-игры в OBS
Параметры запуска Steam
obs-gamecapture %command%

Vulkan обычно захватывается без этого параметра.

05

OBS и звук

Видео кодирует RX 580. Игра, Vesktop и музыка идут отдельными дорожками.

Выбери FFmpeg VAAPI H.264

OBS ставь нативно через Nobara Welcome или DNF App Center, не Flatpak. В выводе выбери расширенный режим и выставь настройки ниже.
ЭнкодерFFmpeg VAAPI H.264
БитрейтCBR / 6000 Кбит/с
Ключевые кадры2 секунды
ПрофильHigh
Стартовое разрешение1664x936 / 60 FPS

Нагрузка на Ryzen станет низкой, но не нулевой. Кто обещает ровно 0% - пиздит. OBS все равно собирает сцену и крутит плагины.

Картинка сыпется в движении
Попробуй 1080p30 или 720p60. RX 580 старая, и надпись 1080p60 сама по себе качество не добавляет.

Раздели звук через PipeWire

В OBS добавь отдельный Application Audio Capture для игры, Vesktop и музыки. Не захватывай весь Desktop Audio одной кучей.
Дорожка 1Игра
Дорожка 2Vesktop
Дорожка 3Музыка
DonationAlerts
Добавь источник Браузер и вставь ссылку виджета DonationAlerts. CEF уже есть в нативной сборке OBS для Nobara.
Плагин Application Audio Capture
sudo dnf install obs-studio-plugin-pipewire-audio-capture -y
06

Две системы

Windows 11 и Nobara на одном NVMe. Работает, но резервная копия обязательна.

Стоп. Один диск для двух систем рискованнее двух отдельных. Не форматируй существующий EFI-раздел и сделай копию важных файлов до любых игр с разметкой.

Переведи часы Windows в UTC

После команды перезагрузи Windows и Nobara. Еще отключи Fast Startup в Windows. Эта хрень любит оставлять диски в полумертвом состоянии.
Оставить Nobara в режиме UTC
timedatectl set-local-rtc 0
Windows Terminal от администратора
reg add "HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /d 1 /t REG_DWORD /f

Показывай GRUB 10 секунд

Выполни команды по очереди и перезагрузи ПК.
Показывать меню
sudo grub2-editenv - unset menu_auto_hide
Таймаут 10 секунд
sudo sed -i 's/^GRUB_TIMEOUT=.*/GRUB_TIMEOUT=10/' /etc/default/grub
Пересобрать конфигурацию
sudo grub2-mkconfig -o /boot/grub2/grub.cfg
07

Если все сломалось

Пять команд. Без лекции на сорок минут.

Обновление Nobara зависло или ругается

Терминал
nobara-sync

Пропал звук

Терминал
systemctl --user restart pipewire pipewire-pulse wireplumber

Зависла игра через Wine

Терминал
wineserver -k

Wine вообще не понял намек

Только если мягкий способ не помог
killall -9 portproton wine xwininfo

Посмотреть ошибки текущей загрузки

Терминал
journalctl -b -p err..alert

Посмотреть упавшие службы

Терминал
systemctl --failed

Если после крупного обновления команда перестала работать, сначала смотри официальную Wiki, а не видос трехлетней давности.
