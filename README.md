# NOBARA / ТВОЙ ПК

Интерактивный русскоязычный гайд по уже установленной Nobara Linux 43 KDE Plasma 6 Wayland для новичка, который переходит с Windows 11.

## Конфигурация

- Ryzen 5 2600;
- Radeon RX 580 8 ГБ;
- 16 ГБ оперативной памяти;
- Gigabyte B450M S2H;
- NVMe 512 ГБ с Windows 11 и Nobara;
- Acer 75 Гц и ViewSonic 60 Гц.

## Как устроен интерфейс

Сайт состоит из двух основных уровней и отдельной пасхалки:

1. `/` - самостоятельный полноэкранный Welcome с кнопками входа и общих настроек.
2. `/guide` - оболочка приложения с отдельным экраном для каждой темы.
3. `/tribunal` - интерактивный «Линуксовый трибунал» с показаниями, уликами и разными приговорами. Он не входит в нумерацию, карту и порядок разделов гайда.

Внутри гайда есть карта маршрута и одиннадцать тематических экранов, всего двенадцать самостоятельных экранов:

- проверка dual-boot, `/boot` и общего EFI;
- Nobara Welcome, обновление, проверка штатных zram, falcond и NVMe scheduler, RPM, DNF App Center, пользовательский Flatpak, Bottles и очистка места;
- мониторы, Wayland, захват экрана, ввод, KWallet и Baloo;
- RX 580, установленный LACT, андервольт и откат;
- Steam, PortProton, Lutris, Heroic, ретро-игры, проверка совместимости и MangoHUD;
- OBS, PipeWire и VK Видео Live;
- Windows UTC, GRUB и Nobara Drive Mount Manager;
- системный звук, Bluetooth, микрофон, контроллеры и Steam Input;
- единый маршрут восстановления от зависшей Plasma до прошлого ядра, журналов и загрузочной флешки;
- отдельная «Лаборатория тонкой настройки» с аргументами ядра и BLS, A/B-замерами MangoHUD, рискованным экспериментом `mitigations=off`, диагностикой Btrfs, NVMe, Mesa и RADV;
- «Заметки» с постоянно видимым белым списком диагностических и штатных команд, ожидаемым результатом и копированием.

Базовая диагностика zram, falcond, профиля питания, NVMe scheduler и preload остается в «Базе после установки», рядом с объяснением штатных механизмов Nobara. Продвинутые эксперименты вынесены на самостоятельный экран и не объявлены обязательной «оптимизацией»: у каждого есть исходная проверка, измерение, риск и полный откат. Для Ryzen 5 2600 по-прежнему не предлагается программное повышение TDP или ручной разгон: PBO у этого поколения не поддерживается, а безопасный предел нельзя определить без точной ревизии платы, охлаждения и измерений.

Навигация меняет экраны без перезагрузки страницы. Диагностика и откат раскрываются непосредственно внутри связанного шага. На сайте нет чек-листа, отметок выполнения и общего прогресса.

## Стек

- Next.js 16 и React 19;
- TypeScript;
- Framer Motion для переходов, контейнерных анимаций и пружинного движения;
- Radix UI для диалогов, подсказок и раскрывающихся блоков;
- Zustand для состояния активного экрана без сохранения в браузере;
- Tailwind CSS и собственная система Material 3 Expressive токенов;
- Manrope Variable и JetBrains Mono Variable из npm-пакетов Fontsource.

Полосы прокрутки скрыты во всех браузерах, но прокрутка колесом, тачпадом, клавиатурой и пальцем остается рабочей.

В настройках есть облегченный режим для слабых ПК и ноутбуков. Он останавливает постоянные Framer Motion-анимации, отключает размытия, тяжелые тени, фоновые эффекты и откладывает отрисовку далеких шагов. Режим действует до обновления страницы и не записывается в браузерное хранилище.

LocalStorage используется только для размера типографики. Ключ: `rx-nobara-text-scale`.

## Структура проекта

- `app/page.tsx` - Welcome;
- `app/guide/page.tsx` - маршрут приложения;
- `app/tribunal/page.tsx` - отдельный маршрут пасхалки вне гайда;
- `components/welcome` - стартовый экран и переход во внутрь;
- `components/tribunal/TribunalApp.tsx` - интерактивное судебное заседание без сохранения состояния;
- `components/guide/GuideApp.tsx` - оболочка и смена сцен;
- `components/guide/GuideNavigation.tsx` - боковая навигация, мобильная панель и переключение экранов;
- `components/guide/GuidePrimitives.tsx` - Material-компоненты действий, диагностики и настроек;
- `components/guide/screens` - отдельный модуль каждого раздела;
- `components/guide/guide-store.ts` - непостоянное Zustand-состояние;
- `app/globals.css` - токены, цветовые темы, адаптивность и движения.

## Локальный запуск

```bash

npm run dev
```

Открой `http://localhost:3000`.

```bash
npm run lint
npm run typecheck
npm run build
```

## Публикация

Сайт использует статический экспорт Next.js. Для GitHub Pages сборка создается с базовым путем репозитория, после чего содержимое `out` копируется в `docs`:

```bash
NEXT_PUBLIC_BASE_PATH=/rxnobarawiki npm run build
rm -rf docs
cp -R out docs
touch docs/.nojekyll
```

GitHub Pages раздает папку `/docs` из рабочей ветки. Основной источник системных рекомендаций - [официальная Nobara Wiki](https://wiki.nobaraproject.org/).
